\section{Selected Software \& Research Engineering Projects}

\textbf{PEKS-NDN Cryptographic Reference Implementation} (in progress) \hfill Rust
\begin{itemize}
	\item Reimplementing published doctoral work on PEKS-based NDN name privacy in Rust using BLS12-381 asymmetric pairings through arkworks, translating the original PBC Type A symmetric construction while reasoning about source- and target-group placement.
	\item Implemented KeyGen, Encrypt, Trapdoor, Test, and serialization, with hash-to-curve using the arkworks construction following the RFC 9380 hash-to-curve design.
	\item Developed automated tests for expected determinism, probabilistic encryption, and end-to-end correctness; documented protocol assumptions, design rationale, and implementation decisions for experimental evaluation.
	\item Repository: \href{https://github.com/kyitharko/peks_based_ndn}{github.com/kyitharko/peks\_based\_ndn}.
\end{itemize}
