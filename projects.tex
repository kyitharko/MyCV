\section{Selected Security Research \& Engineering Projects}

\textbf{PEKS-Based NDN Name-Privacy Protocol} \hfill C++ / PBC
\begin{itemize}
	\item Implemented a PEKS-based Named Data Networking name-privacy protocol in C++ using the Pairing-Based Cryptography (PBC) library, translating cryptographic and protocol design into a working research prototype.
	\item Implemented pairing-based cryptographic operations and protocol logic for key generation, encryption, and trapdoor/search operations.
	\item Evaluated cryptographic and network-forwarding performance, and investigated trapdoor assignment in two-tier network topologies.
	\item Contributed to two peer-reviewed publications as part of doctoral research.
\end{itemize}

\textbf{PEKS-NDN Cryptographic Reference Implementation} (in progress) \hfill Rust
\begin{itemize}
	\item Reimplementing the published research in Rust with BLS12-381 and arkworks, adapting the original symmetric-pairing construction to asymmetric source and target groups.
	\item Implemented KeyGen, Encrypt, Trapdoor, Test, serialization, and hash-to-curve, with automated correctness tests and design documentation.
	\item Repository: \href{https://github.com/kyitharko/peks_based_ndn}{github.com/kyitharko/peks\_based\_ndn}.
\end{itemize}
