\section{Selected Protocol \& Cryptography Research}

\textbf{PEKS-Based NDN Name-Privacy Protocol} \hfill C++ / PBC
\begin{itemize}
	\item Designed and implemented a PEKS-based protocol strategy for name privacy in Named Data Networking, translating cryptographic and protocol designs into a C++ implementation using the Pairing-Based Cryptography (PBC) library.
	\item Analyzed architectural, security, and performance trade-offs in the protocol design, and evaluated its cryptographic and network-forwarding behavior.
	\item Extended the research to two-tier network architectures and trapdoor assignment.
	\item Resulted in two peer-reviewed publications.
\end{itemize}

\textbf{PEKS-NDN Cryptographic Reference Implementation} (in progress) \hfill Rust
\begin{itemize}
	\item Reimplementing the published protocol in Rust with BLS12-381 and arkworks, adapting the original symmetric-pairing construction to asymmetric source and target groups.
	\item Implemented KeyGen, Encrypt, Trapdoor, Test, serialization, and hash-to-curve, with automated correctness tests and design documentation.
	\item Repository: \href{https://github.com/kyitharko/peks_based_ndn}{github.com/kyitharko/peks\_based\_ndn}.
\end{itemize}
