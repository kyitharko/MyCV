\section{Selected Security Research Project}

\textbf{PEKS-NDN Cryptographic Reference Implementation} (in progress) \hfill Rust
\begin{itemize}
	\item Reimplementing the PEKS-based Named Data Networking privacy strategy from previous doctoral research in Rust using BLS12-381 asymmetric pairings through the arkworks ecosystem.
	\item Translated the original symmetric-pairing construction based on PBC Type A pairings to an asymmetric pairing setting, reasoning about source-group and target-group placement to preserve cryptographic equation correctness.
	\item Implemented the core cryptographic operations---KeyGen, Encrypt, Trapdoor, and Test---with hash-to-curve using the arkworks construction following the RFC 9380 hash-to-curve design.
	\item Developed automated tests for determinism where expected, probabilistic encryption behavior, and end-to-end round-trip correctness.
	\item Documented the cryptographic design rationale, protocol assumptions, interoperability considerations, and implementation decisions required when moving from symmetric to asymmetric pairings.
	\item Repository: \href{https://github.com/kyitharko/peks_based_ndn}{github.com/kyitharko/peks\_based\_ndn}.
\end{itemize}
