\section{Selected Research Projects}

\textbf{PEKS-Based NDN Privacy-Preserving Protocol} \hfill C++ / PBC
\begin{itemize}
	\item Designed a privacy-preserving networking protocol (PEKS-based Named Data Networking) and implemented its pairing-based cryptographic core in C++ using the Pairing-Based Cryptography (PBC) library.
	\item Integrated the cryptographic scheme into the network-forwarding protocol and reasoned about the correctness and security properties of the construction.
	\item Experimentally evaluated cryptographic and network-forwarding performance; extended the design to two-tier network architectures and trapdoor assignment.
	\item Resulted in two peer-reviewed publications.
\end{itemize}

\textbf{PEKS-NDN Cryptographic Reference Implementation} (active development) \hfill Rust
\begin{itemize}
	\item Reimplementing a published cryptographic networking protocol in Rust, translating an academic C++/PBC construction into idiomatic Rust using arkworks and BLS12-381.
	\item Migrated the underlying pairing construction from symmetric to asymmetric source/target groups -- a correctness-critical refactor requiring careful reasoning about group placement and API semantics.
	\item Implemented KeyGen, Encrypt, Trapdoor, and Test operations, plus hash-to-curve following RFC 9380 design principles, with automated correctness tests covering the full pipeline.
	\item Active, openly documented research/reference implementation -- not production or commercial software. Repository: \href{https://github.com/kyitharko/peks_based_ndn}{github.com/kyitharko/peks\_based\_ndn}.
\end{itemize}
