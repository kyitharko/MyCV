\section{Selected Software \& Research Engineering Projects}

\textbf{PEKS-Based NDN Research Prototype} \hfill C++ / PBC
\begin{itemize}
	\item Implemented the published PEKS-based NDN name-privacy strategy in C++ using the Pairing-Based Cryptography (PBC) library.
	\item Implemented pairing-based cryptographic operations and protocol logic for KeyGen, encryption- and search-related operations, and experimental evaluation.
	\item Benchmarked cryptographic and networking performance as part of doctoral research that contributed to two peer-reviewed publications.

	\item Implemented KeyGen, Encrypt, Trapdoor, Test, serialization, and hash-to-curve, with automated correctness tests and design documentation.
	\item Repository: \href{https://github.com/kyitharko/peks_based_ndn}{github.com/kyitharko/peks\_based\_ndn}.
