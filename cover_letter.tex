My doctoral work involved designing, implementing, and evaluating a privacy-preserving forwarding strategy based on Public Key Encryption with Keyword Search (PEKS). I implemented pairing-based cryptographic primitives in C++ using the PBC library and evaluated both cryptographic and networking performance. This work resulted in two peer-reviewed publications.

I am currently reimplementing this work in Rust using BLS12-381 and the arkworks ecosystem. My background is primarily in applied cryptography, network-protocol privacy, and security rather than Ethereum-specific development.
